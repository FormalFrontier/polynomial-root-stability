# Polynomial Root Stability

**Authors: Formal Frontier Agents. License: Apache-2.0.** See [LICENSE](LICENSE).

This source-independent Lean library studies how the field generated by
polynomial roots behaves under small changes in the coefficients, together with
quantitative root and factor lifting in complete ultrametric normed fields.

## Headline results

**Root-generated fields are locally constant at fixed degree.** Fix normed
fields `K`, `L` with a normed algebra structure `L / K` satisfying
`IsKrasner K L`. For any nonzero separable polynomial `f : K[X]` that splits
in `L`, there is a radius `ε > 0` such that every polynomial `g : K[X]` with
the same `natDegree`, also splitting in `L`, and with
`‖g.coeff i - f.coeff i‖ < ε` for every coefficient index `i`, is separable
and generates exactly the same intermediate field over `K` as `f`.
The [ordinary-coefficient theorem](PolynomialRootStability/Normalization.lean#L214)
applies without monicity and derives comparison nonzeroness internally.

There are also [monic](PolynomialRootStability/Krasner.lean#L565) and
[scale-invariant normalized-coefficient](PolynomialRootStability/Normalization.lean#L45)
versions of this result. The normalized version measures closeness after
dividing each polynomial by its own leading coefficient and requires `g ≠ 0`
explicitly; do not interchange the normalized and ordinary coefficient bounds.

These results let downstream developments perturb coefficients while keeping
the root-generated subfield fixed. The ambient extension and both splitting
assumptions are inputs, not conclusions. Equality is between the subfields
`IntermediateField.adjoin K (f.rootSet L)` and
`IntermediateField.adjoin K (g.rootSet L)` inside that fixed `L`, not an
equivalence of canonical splitting-field objects. Fixed degree is essential;
no stability for arbitrary variable-degree families or nonseparable references
is asserted. Mathlib supplies Krasner's lemma and polynomial-root continuity;
this library combines them with finite-root estimates and coefficient
normalization to obtain the stated local-constancy interfaces. See the
[historical root-field API reference](docs/README.md) and the
[generic checked-use clients](PolynomialRootStabilityTest/Normalization.lean).

### Local polynomial norm scaling

Let `R` be an ultrametric commutative seminormed ring with multiplicative
seminorm. If `f : R[X]` satisfies `∀ n, ‖f.coeff n‖ ≤ M`, `‖a‖ ≤ 1`, and
`M * ‖b - a‖ < ‖f.derivative.eval a‖`, then

```lean
‖f.eval b - f.eval a‖ = ‖f.derivative.eval a‖ * ‖b - a‖
```

The theorem
[`Polynomial.norm_eval_sub_eq_of_mul_norm_sub_lt_norm_derivative`](PolynomialRootStability/Ultrametric.lean)
requires no root, division, completeness or separated norm. Only the anchor
`a` is assumed to lie in the unit ball; the bound on `b` follows from the
hypotheses. Zero seminorm distance is allowed without identifying the points.
The [3-adic Newton example](PolynomialRootStabilityTest/NewtonNaturality.lean)
instantiates this identity at `a = 1` and `b = 5 / 2` for `X² - 4`, with
nonzero evaluation-difference norm and displacement norm both equal to `1 / 3`.

The two-point theorem
[`Polynomial.norm_eval_sub_eval_eq_of_mul_norm_sub_lt_norm_derivative`](PolynomialRootStability/Ultrametric.lean)
gives `‖f.eval c - f.eval b‖ = ‖f.derivative.eval a‖ * ‖c - b‖`
under the same assumptions on `R`, `f`, `M`, and `a` whenever both
`M * ‖b - a‖ < ‖f.derivative.eval a‖` and
`M * ‖c - a‖ < ‖f.derivative.eval a‖`; the derivative factor remains at the
original anchor `a`.

When `R` is a normed commutative ring, the same coefficient and anchor bounds
give injectivity on this strict ball. The theorem
[`Polynomial.injOn_eval_of_mul_norm_sub_lt_norm_derivative`](PolynomialRootStability/RootUniqueness.lean)
expresses this as `Set.InjOn`; the anchor need not be a root.

### Root uniqueness in an ultrametric normed ring

Let `R` be an ultrametric normed commutative ring with multiplicative norm,
let `f : R[X]` satisfy `∀ n, ‖f.coeff n‖ ≤ M`, and let `y` be a root with
`‖y‖ ≤ 1`. Then every root `x` satisfying
`M * ‖x - y‖ < ‖f.derivative.eval y‖` equals `y`. The criterion
[`Polynomial.eq_of_eval_eq_zero_of_mul_norm_sub_lt_norm_derivative`](PolynomialRootStability/RootUniqueness.lean)
requires neither division nor completeness, and does not assume `‖x‖ ≤ 1`:
the derivative bound and the strict inequality imply that bound. The local norm
scaling identity forces `‖x - y‖ = 0`, and separation gives equality.
The coefficient bound is arbitrary; it need not be one.

The [3-adic Newton example](PolynomialRootStabilityTest/NewtonNaturality.lean)
for `X² - 4` at `1` uses this criterion to identify every source root in the
strict radius-one ball with `-2`. The same example retains convergence under
the embedding into the 3-adic complex field and uniqueness among all target
roots in the target ball; the other root `2` lies on the excluded boundary.

### Quantitative Newton lifting

For a complete ultrametric normed field `K`, a polynomial `f : K[X]` with
`∀ n, ‖f.coeff n‖ ≤ 1`, and `‖a₀‖ ≤ 1`, the hypothesis
`‖f.eval a₀‖ < ‖f.derivative.eval a₀‖²` gives an integral root at exact distance
`‖f.eval a₀‖ / ‖f.derivative.eval a₀‖`, with derivative-norm stability and
uniqueness in the open initial-derivative-radius ball. The statement also includes
convergence of the explicit iterates `f.newtonMap^[n] a₀`, integrality of all
iterates, nonzero denominators and derivative-norm stability at every iterate. No monicity, characteristic-zero,
nontrivial-norm, or norm-one derivative hypothesis is imposed. This formulation
uses a real-valued norm, not an arbitrary higher-rank valuation.

The theorem [`Polynomial.exists_root_tendsto_iterate_newtonMap`](PolynomialRootStability/Newton.lean)
uses coefficient-controlled ultrametric estimates and Mathlib’s Banach fixed
point theorem. On the closed ball of radius `δ / d`, where `δ` is the initial
error and `d` the initial derivative norm, the Newton map has contraction constant
`δ / d²`. The proof includes zero initial error and trivially normed fields.
The field-target quotient formula and
[boundary examples](PolynomialRootStabilityTest/NewtonContracts.lean) use the
stock polynomial Newton map and function iteration.
The independent [2-adic input calculation](PolynomialRootStabilityTest/Newton.lean)
uses `X² - 17` at `1`, with nonzero error of norm `1 / 16` and derivative of norm
`1 / 2`, a nonunit in `ℤ_[2]`. Its further convergence client applies the general
theorem; the input calculation is independent of the root-existence proof.
The private [p-adic compatibility clients](PolynomialRootStabilityTest/PadicHensel.lean)
recover the complete existing Hensel interface for arbitrary commutative-semiring
coefficients and the p-adic polynomial distance estimate, without calling the old
root-existence theorem or adding a duplicate public API. The `X² - 1` boundary
calculation shows that uniqueness cannot use the closed derivative-radius ball.

### Quantitative resultant-controlled factorization

Let `K` be a complete ultrametric normed field, and let `f, g₀, h₀ : K[X]`.
Write `m = g₀.natDegree`, `n = h₀.natDegree`, `e = f - g₀ * h₀`,
`δ = e.supNorm` and `r = ‖g₀.resultant h₀‖`, using the natural-degree resultant.
Assume `g₀.supNorm ≤ 1`, `h₀.supNorm ≤ 1`, `e.degree < (m + n : WithBot ℕ)`
and `δ < r²`. Then
[`Polynomial.exists_factorization_of_supNorm_lt_resultant_sq`](PolynomialRootStability/ResultantFactorization.lean)
gives `f = g * h`, preserving each initial factor's degree and leading coefficient.
The corrections have degrees strictly less than `m` and `n`, both factors have
sup norm at most one, and both correction sup norms are at most `δ / r`.

There is no monicity, norm-one-leading-coefficient, characteristic-zero, discreteness,
nontrivial-norm or positive-factor-degree assumption. The strict degree bounds use
`WithBot ℕ`, so degree less than zero forces the zero polynomial. In particular,
both constant initial factors force zero error, and zero error returns the
initial factors. The proof uses the initial Sylvester inverse, finite coefficient
coordinates and Mathlib's Banach fixed-point theorem.

The [5-adic example](PolynomialRootStabilityTest/ResultantFactorization.lean) uses
`g₀ = 5X² + 2`, `h₀ = 5X² + 7` and `f = g₀h₀ + 5⁹X`. Its independently proved
inputs give `r = 5⁻⁴`, `δ = 5⁻⁹` and correction bounds `5⁻⁵`. The full-output client
produces degree-two factors with leading coefficients `5` and these correction
bounds. The leading coefficients and resultant are nonunits in the valuation
integer ring, not in the field.

## Modules and mathematical API

| Import | Main results |
| --- | --- |
| `PolynomialRootStability.Krasner` | `IsKrasner.exists_pos_adjoin_rootSet_eq_of_monic_separable` gives monic local equality and nearby separability; `IsKrasner.exists_pos_adjoin_rootSet_le_of_monic_separable` gives a one-sided inclusion without requiring comparison separability. Supporting lemmas give finite positive root/conjugate separation, quantitative coefficient radii, conditional inclusion, nearby separability and equality. |

| `PolynomialRootStability.Ultrametric` | Uniform coefficient bounds control derivative coefficients, evaluation and differences on the norm unit ball in ultrametric seminormed rings; a first-order Taylor remainder has a quadratic bound in ultrametric seminormed commutative rings. No completeness or norm-one hypothesis is needed. |
| `PolynomialRootStability.Newton` | `Polynomial.newtonMap_apply_eq_sub_div` proves the field quotient formula. `Polynomial.exists_root_tendsto_iterate_newtonMap` proves quantitative lifting, exact distance, derivative-norm stability, convergence, nonzero denominators and open-ball uniqueness. |
| `PolynomialRootStability.ResultantFactorization.Algebra` | Ultrametric determinant and adjugate bounds, resultant and Sylvester-adjugate coefficient bounds, and inverse composition identities. |
| `PolynomialRootStability.ResultantFactorization.Coordinates` | Finite coefficient/sup-norm identities, including empty vectors, and ultrametric sup-norm sum, difference and product bounds. The Gauss-norm product bound allows nonarchimedean, nonnegative, zero-preserving submultiplicative coefficient functions. |
| `PolynomialRootStability.ResultantFactorization` | `Polynomial.exists_factorization_of_supNorm_lt_resultant_sq` gives bounded-degree quantitative factor lifting with degree and leading-coefficient preservation. |
| `PolynomialRootStability` | Publicly reexports the stability, ultrametric, Newton and resultant-factorization APIs; test leaves are separate. |

The [historical root-field API snapshot](docs/README.md) gives the native displayed
signatures, docstrings and source links for the existing 14 Krasner/Normalization
production theorems and nine **publicly named** clients in their two test leaves.
It retains its original eight source/pin hashes and older mathlib revision; it
is not freshly generated for the current configuration and covers neither Newton
nor Ultrametric. Use the linked Lean sources for those APIs and proofs.
Displayed signatures are documentation, not proof checks.

The two coefficient radii are different: the normalized theorem assumes
`g ≠ 0` and closeness of the coefficients of `g * C g.leadingCoeff⁻¹` and
`f * C f.leadingCoeff⁻¹`; the ordinary theorem proves `g ≠ 0` internally and
asks for closeness of `g.coeff i` and `f.coeff i`. No extra separability
assumption on `g` is needed. The supporting positive separation lemmas need
no `IsKrasner` instance. The reverse Krasner step compares two selected-root
errors and one error at another root; using only a one-sided Krasner bound
would not establish equality. Nonzero constants and empty root sets are
covered (the zero polynomial is excluded from normalization).

The root-field conclusion is equality of `IntermediateField.adjoin K (f.rootSet L)`
and `IntermediateField.adjoin K (g.rootSet L)`, **not** equivalence of canonical
splitting-field objects. This library does not provide separate real/complex
variants, arbitrary variable-degree families, nonseparable-reference stability,
or a claim of complete formalization of its motivating mathematical source.

## Build and check

From the repository root, install the exact toolchain from `lean-toolchain`
(Lean `v4.34.0-rc2`), with mathlib pinned by `lakefile.toml` and the exact
resolved nine-package graph in `lake-manifest.json`:

```sh
elan toolchain install "$(cat lean-toolchain)"
lake exe cache get
LEAN_NUM_THREADS=2 lake --wfail build
```

The default build compiles the production modules, the root reexport and
the **separate** `PolynomialRootStabilityTest` library with explicit Krasner,
Normalization, Newton, NewtonContracts, PadicHensel and ResultantFactorization roots.
It does not import tests into the production root. Warning-fatal compilation and
axiom auditing are distinct checks; the build command alone is not a
full-axiom-audit result. The direct Krasner/Normalization targets remain available.
Always fetch the matching precompiled mathlib cache before building; after
changing dependency pins or replacing `.lake`, fetch it again.
`LEAN_NUM_THREADS=2` configures Lean's runtime; it is not a limit on total
processes or memory. Build time depends on the available cache and hardware.

Optional API documentation tooling is not required for ordinary library use.

For example, the named checked client
`PolynomialRootStabilityTest.aggregate_ordinary_stability` in
`PolynomialRootStabilityTest/Normalization.lean` imports the aggregate root
and specializes the ordinary API at independent base/ambient universes:

```lean
import PolynomialRootStability

open Polynomial

noncomputable section

universe u v

variable {K : Type u} {L : Type v}
  [NormedField K] [NormedField L] [NormedAlgebra K L] [IsKrasner K L]

example {f : K[X]} (hf0 : f ≠ 0) (hfsep : f.Separable)
    (hfsplit : (f.map (algebraMap K L)).Splits) :
    ∃ ε : ℝ, 0 < ε ∧ ∀ {g : K[X]},
      g.natDegree = f.natDegree →
      (∀ i : ℕ, ‖g.coeff i - f.coeff i‖ < ε) →
      (g.map (algebraMap K L)).Splits →
      g.Separable ∧
        IntermediateField.adjoin K (f.rootSet L) =
          IntermediateField.adjoin K (g.rootSet L) :=
  IsKrasner.exists_pos_adjoin_rootSet_eq_of_separable hf0 hfsep hfsplit
```

The root-field 2-adic test clients choose `K = L = ℚ_[2]`. They check constant and
nonmonic degree-one specializations; they **do not** test nontrivial ambient
field extensions. Direct and aggregate imports both have named checked
clients; none assumes the desired field equality as a hypothesis.
