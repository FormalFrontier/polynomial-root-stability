### IsKrasner.exists_pos_root_continuity_bound_lt_of_monic

```lean
theorem IsKrasner.exists_pos_root_continuity_bound_lt_of_monic {K₀ : Type u_3} {L₀ : Type u_4} [NormedField K₀] [NormedField L₀] [NormedAlgebra K₀ L₀] (f : Polynomial K₀) (hfm : f.Monic) : ∃ (ε : ℝ), 0 < ε ∧ ∀ x ∈ f.rootSet L₀, ∀ (x' : L₀), IsConjRoot K₀ x x' → x ≠ x' → ((↑f.natDegree + 1) * ε) ^ (↑f.natDegree)⁻¹ * max ‖x‖ 1 < ‖x - x'‖
```

A monic polynomial admits one positive coefficient radius for which the
quantitative root-continuity estimate is smaller than every nontrivial
conjugate distance of every root. The radius is uniform because the reference
root set is finite. The constant-polynomial case is handled vacuously; in the
nonempty-root case, monicity supplies the positive degree needed to invert the
real exponent.

[Source](../PolynomialRootStability/Krasner.lean#L171) (docstring begins on line 171).
